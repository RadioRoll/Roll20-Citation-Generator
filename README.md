## Roll20-Citation-Generator  
A script for creating dynamic and modern styled citations/fines/tickets for Modern TTRPGs, almost instantly.  
Useable in prep and play, with customisable fields for:  
  - Name
  - Citation Title  
  - Issuing Agency  
  - Offense   
  - Location  
  - Fine  
  - Date

### How it works  
1. The GM at any time types `!cite` into chat.   
2. To Issue a ticket, click `Issue`.  
3. Fillout the fields promted. *(seen above)*

  And you're done. :) The system automatically creates  
  a formatteed citation/ticket in chat and as a handout.

## COMMANDS
`!cite`       - Open GM citation terminal   
`!citehelp`   - Display instructions  
   
 #### CITATION STORAGE.   
 Individual handouts contain citation records. One master register handout contains the index.  
 GM can access a menu for manipulating the citation automatically. Changing the state of the handout document instantly.   
 The index is GM only.  
 The index has clickable links to all listed citations for easy recall.  
 API state stores ONLY the next citation number. For minimal data impact.  
 Access the Manage menu to delete handouts from the system entirely.
